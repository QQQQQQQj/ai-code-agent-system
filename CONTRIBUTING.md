# Contributing to AI Code Agent System

Thank you for your interest in contributing to AI Code Agent System! We welcome contributions from the community.

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/QQQQQQQj/ai-code-agent-system.git
cd ai-code-agent-system
pip install -e ".[dev]"
```

2. Run tests:
```bash
pytest -n auto
```

## Code Style

- Follow PEP 8 guidelines
- Use type hints for all functions
- Write docstrings for public APIs
- Keep code simple and readable

## Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Commit your changes: `git commit -m 'Add my feature'`
4. Push to branch: `git push origin feature/my-feature`
5. Open a Pull Request

## Reporting Issues

Please use GitHub Issues to report bugs or request features.
